# Web 安全漏洞复现笔记

张旭波的个人 Web 安全学习记录 —— 每打一道靶场题，就在这里留一份复现笔记。

## 这个仓库是什么

不是题解合集，而是**自己的复现记录**。每份笔记回答四个问题：

1. 这个漏洞**为什么会存在**（原理，不是现象）
2. 我**怎么打出来的**（可复现的步骤和 payload）
3. 该怎么**修**（开发视角，说得出修复方案才叫真懂）
4. 面试会**怎么问**（预习式整理，面试时直接调用）

## 目录结构

## 怎么用

1. 复制 `TEMPLATE.md`，按 `模块/序号-题目名.md` 命名
2. **先做题，再写笔记** —— 别一边看题解一边抄
3. 写完把「面试问答」那节读一遍，答不上来就说明还没真懂
4. 每完成一个模块，更新上面的进度表
